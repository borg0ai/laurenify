This Copilot home has no valid laurenify model sheet, and laurenify ships no default Copilot models. When this session first invokes one of the skills that dispatch on role models, load `setup-pstack` with the `skill` tool and finish it before that skill's first step, even for a small question. It asks the user each model question with `ask_user`, writes the sheet that later sessions reuse, and checks it. It never picks a model the user has not chosen, so when `ask_user` is not available it writes no sheet, and the roles run on the session's model.
